# Course Workspace · DIGI 230

An interactive course workspace prototype exploring the future of education with AI, including ethics, governance, student agency, and personalized learning. The prototype supports discussion of these possibilities rather than representing a production learning platform.

[Open the live prototype](https://digi230-three-student-workspaces.londondg.chatgpt.site/)

## Explore

- Course conversations, notes, and ideas
- Three student-specific workspace adaptations: reading, visual thinking, and task focus
- Settings and simulated AI assistance

## Run locally

This is a static HTML, CSS, and JavaScript project. No build or API key is required.

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Assistant behavior is simulated; this is a classroom design prototype.

## Files

`index.html` is the entry point. `app.js`, `assistant.js`, and the CSS files implement the workspace. `concepts/` contains additional student workspace concepts, `examples/` contains reference images, and `fonts/` includes Inter and its license.
